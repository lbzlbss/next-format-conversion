上传 VAP 资源预览 alpha 通道，支持缩放与格式转换，适合动效研发联调。

## 操作步骤

1. 在首页选择 **VAP 动效**。
2. 上传 `.mp4` + `.json`（或含 vapc 的 VAP 资源包）。
3. 在预览区检查 RGB 与 Alpha 是否对齐。
4. 按需调整缩放、输出格式后导出。

## 参数说明

- **scale**：预览/导出缩放比例，非 1:1 时需确认 vapc 信息与源分辨率一致。
- **format**：输出容器格式，需与目标播放器（腾讯 VAP 等）兼容。

## 常见问题

- **花屏 / alpha 错位**：多为 vapc 宽高、帧信息与视频不一致；重新用官方 vap-tool 生成 vapc。
- **播放器解析失败**：检查 json 中 `info` 字段与视频路径是否匹配。
- **缩放后模糊**：提高源分辨率或减少缩放倍率。
